# 📅 Clinic Calendar Maker Pro

เว็บแอปพลิเคชันสร้างและจัดการปฏิทินเวลาทำการคลินิก / ร้านค้า พร้อมระบบพิมพ์กระดาษ **A4 แนวนอน (Landscape) พอดี 1 หน้าอัตโนมัติ** และระบบส่งออกรูปภาพความละเอียดสูง

---

## ✨ ฟีเจอร์เด่น (Features)

1. **Auto-fit A4 Landscape Printing (พิมพ์ A4 แนวนอน 1 แผ่นพอดี 100%)**
   - คำนวณความสูงของแถวตามจำนวนสัปดาห์ในเดือนนั้นๆ (4, 5 หรือ 6 สัปดาห์) โดยอัตโนมัติ
   - หน้ากระดาษไม่ล้น ไม่ขาดตอน เมื่อสั่งพิมพ์ หรือ Save as PDF

2. **🖼️ บันทึกเป็นรูปภาพความละเอียดสูง (Export PNG / JPEG)**
   - บันทึกตารางปฏิทินเป็นไฟล์รูปภาพความละเอียดสูง (2.5x Retina) ในคลิกเดียว
   - พร้อมนำไปโพสต์ลง Facebook Page, LINE Official Account หรือส่งให้คนไข้ได้ทันที

3. **🕒 ระบบพรีเซ็ตเวลาทำการ (Schedule Presets & One-click Auto-fill)**
   - ตั้งค่าเวลาเปิด-ปิดเริ่มต้นแยกตามวัน (จันทร์ - อาทิตย์)
   - ปุ่ม **"เติมเวลาเริ่มต้นทั้งเดือน"** กดปุ๊บใส่ข้อมูลครบทั้งเดือนปั๊บ
   - เครื่องมือด่วน: "เปิด จ.-ศ.", "ปิด ส.-อา.", "ล้างตาราง"

4. **🏥 ปรับแต่งโปรไฟล์และแบรนด์คลินิก (Clinic Profile & Custom Branding)**
   - แก้ไขชื่อคลินิก, คำบรรยาย หรือเบอร์โทรติดต่อ ได้ทั้งจากการคลิกแก้บนกระดาษโดยตรง หรือผ่านเมนูตั้งค่า
   - อัปโหลดเปลี่ยนรูปภาพ Logo, QR Code Facebook และ QR Code LINE ได้เองจากเครื่อง

5. **🎨 ธีมสีระดับพรีเมียม (Color Themes)**
   - Medical Navy (มาตรฐาน)
   - Modern Teal (ฟ้าอมเขียว)
   - Royal Blue (น้ำเงินสดใส)
   - Emerald Health (เขียวสุขภาพ)
   - Royal Purple (ม่วงสง่างาม)
   - Warm Coral (ส้มคอรัล/ชมพู)

6. **💾 ระบบจำข้อมูลอัตโนมัติ (LocalStorage Auto-save)**
   - บันทึกการเปลี่ยนแปลงทั้งหมดไว้ในเบราว์เซอร์อัตโนมัติ รีเฟรชหน้าจอข้อมูลไม่สูญหาย

7. **📢 หมายเหตุประจำวัน & แถบประกาศสำคัญท้ายปฏิทิน**
   - เพิ่มหมายเหตุใต้แต่ละวัน เช่น "วันหยุดนักขัตฤกษ์", "หยุดพิเศษ", "เปิดตรวจเฉพาะเช้า"
   - แถบประกาศหรือแจ้งเตือนสำคัญด้านล่างปฏิทิน

---

## 🚀 วิธีใช้งาน

1. เปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari ฯลฯ)
2. เลือกเดือนและปี พ.ศ. ที่ต้องการจัดทำ
3. ปรับเปลี่ยนสถานะวัน (เปิด / ปิด / พิเศษ) และระบุช่วงเวลาตามต้องการ
4. กดปุ่ม **"พิมพ์ / บันทึก PDF"** หรือ **"บันทึกเป็นรูปภาพ (PNG)"** ได้ทันที
